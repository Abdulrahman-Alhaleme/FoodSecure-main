# FoodSecure Jordan 🌱

A responsive, interactive website that explores **food security in Jordan**, built using only **HTML, CSS, and JavaScript**.  
The project covers agriculture, irrigation, crops, plants, vertical farming, and plant diseases in Jordan with data visualization, filtering, and modern UI.

---

## 🚀 Features

- **7 Pages**:
  - Home
  - Agriculture
  - Irrigation
  - Crops
  - Plants
  - Vertical Farming
  - Plant Diseases

- **Local JSON Data** (`assets/data.json`)  
  Stores information on agriculture, irrigation systems, crops, and plants (100+ entries).

- **Charts & Stats**  
  Built using [Chart.js](https://www.chartjs.org/) for agriculture/irrigation statistics.

- **Search & Filter System**  
  Allows searching crops/plants by name, type, or rarity.

- **Pagination**  
  Crops and Plants displayed as cards with pagination controls.

- **Light/Dark Mode**  
  User preference saved in `localStorage`.

- **Scroll Progress Bar**  
  Visual indicator of how much content has been explored.

- **Animations & Interactions**  
  Smooth entrance animations, hover effects, parallax hero image, card tilt effect, and popup modals.

- **Splash Screen**  
  Initial lazy splash animation before showing the homepage.

- **Fully Responsive**  
  Works beautifully on desktop and mobile.
